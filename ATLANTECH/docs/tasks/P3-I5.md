## 1. What is asked

The lead's Sprint 3 handoff: most of it already exists in `atlantech:worker-accounts`; review it against DEC-08 and `WorkerGrantsTest`, complete what is missing and close the task. Roadmap "done when": a worker cannot touch tables it does not own.

**Done when** (each line is checkable by a test):

- [ ] Every worker role has exactly the DEC-08 "Final grants" rights: reads, inserts and updated columns, compared on the rights MySQL holds, for all six roles.
- [ ] No role holds anything else: no DELETE, no DDL, no grant option, no other role, no other database.
- [ ] No worker has any right on `audit_logs`.
- [ ] A new table cannot arrive without a decision: every table in the schema is either readable by workers or on the excluded list.

**Out of scope:** the application's own database account (section 7) · running the command on a server (deployment) · the CT-15 / DEC-08 text update for `yard_runs.retry_count` (P1-B3 follow-up F35, a contract change).
