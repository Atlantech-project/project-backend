## 3. Design

### Endpoints

None.

### Data

- **Input:** `docs/reference/database/PortSync.sql` + base DDL fixes + Report A final forms + FCM changes 1 and 3 + CT-17 §7 additions + DEC-36 index.
- **Migrations:** one per table, `…_create_<table>_table.php`, ordered by module so every foreign key points to an earlier table. Columns, types, defaults, comments (UTF-8 fixed), ENUMs with the exact SQL names, indexes and FK names as in the SQL. Ids `id()` / `foreignId()` (BIGINT UNSIGNED). No `ON DELETE CASCADE` on tables a worker writes.
- **CHECKs and generated columns:** created inside each table's migration (`DB::statement` after `Schema::create`), named as in the DDL fixes (answer 1).
- **`updated_at DATETIME(6)`** (answer 3) on: `users`, `terminals`, `berths`, `tugboats`, `safety_constraints`, `port_shifts`, `equipment`, `storage_facilities`. Tables already carrying `updated_at` keep it, changed to `DATETIME(6)`. Other master-data tables edited from the screens are added during the P1-B2 review.
- **Framework tables:** keep `cache` and `jobs` migrations; the default `users` migration is replaced by the port `users` table, keeping `password_reset_tokens` and `sessions`.
- **Connection:** `config/database.php` sets `timezone => '+00:00'` and the collation `utf8mb4_0900_ai_ci`.
- **Grants:** `database/grants/workers.sql`, the DEC-08 matrix plus the CT-17 §7 column grants.
- **Owner:** Backend for every migration (CT-17). Tables workers read or write are listed in CT-15; the PR carries `ai-impact` and needs one AI Team approval (CT-17 §6; corrected by review finding R1).
- **Enums:** stay as MySQL `ENUM`; PHP enums come in P1-B5.

### Behaviour

Not applicable (no endpoint, no write chain, no audit, no events).

### How the migrations are produced (answer 2)

A one-off Node script, kept outside the repository, reads the corrected SQL, sorts the tables by foreign key, maps names with `table-names.md`, and writes one Schema-builder migration per table. The output is then reviewed and fixed by hand; from this PR on, the migrations are the source of truth (CT-17 §1) and the script is not used again.
