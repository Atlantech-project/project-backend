## 3. Design

### Endpoints

None. `paths: {}` until the first real endpoint (answer 5).

### File `ATLANTECH/openapi/port-api.yaml`

`openapi/` is a new base folder, approved with answer 1.

- `openapi: 3.0.3`; `info`: title, `version: 0.1.0` (answer 6), contact Backend Team, a description linking CT-01 and CT-02. `servers: [{ url: / }]`; paths carry the full `/api/v1/...` as in the CT-02 example.
- `components.securitySchemes`:
  - `cookieAuth`: apiKey in a cookie; Sanctum SPA session with `X-XSRF-TOKEN`.
  - `bearerAuth`: http bearer, for mobile tokens.
- `components.parameters`:
  - `Page`: integer 1..1 000 000, default 1.
  - `PerPage`: integer 1..100, default 25.
  - `AppVersion`, `DeviceId`: headers, required on mobile routes.
  - `IdempotencyKey`: UUID header for mobile writes.
- `components.headers`: `RetryAfter`, `Allow`.
- `components.schemas`:
  - `Problem`: the 6 required members. `code` is an enum of the 16 `ErrorCode` values; `type` is a URI.
  - `ValidationProblem`: `Problem` plus `errors` (a map from field to a list of keys).
  - `VersionConflictProblem`: adds `current {id, version: date-time}`.
  - `AppUpdateRequiredProblem`: adds `min_app_version`.
  - `PageMeta {page, per_page, total}`.
  - `DateTime` note: UTC with `Z`, microseconds.
- `components.responses`: one per `ErrorCode`, named by the enum case (`ValidationFailed`, `VersionConflict`, … `BadRequest`). Each is `application/problem+json` with a matching example (status, code, `message_key`, `detail` from `lang/en`). `MethodNotAllowed` carries `Allow`; `TooManyAttempts` carries `Retry-After`.

### Rules the drift test enforces (`tests/Feature/Api/OpenApiDriftTest.php`)

- The file parses, `openapi` is 3.0.x, and `info.version` is semver.
- Every `/api/v1` route (method + URI, `HEAD` ignored) appears in `paths`, and every operation in `paths` has a route.
- `Problem.code.enum` equals the `ErrorCode` values, in order. Every case has a response named after it, and its example status equals `status()`, its `code` the value and its `message_key` the key.
- `Page` / `PerPage` minimum, maximum and default equal the `PageRequest` constants.

### Spectral

- `ATLANTECH/.spectral.yaml` extends `spectral:oas`.
- `oas3-unused-component` is off while `paths` is empty, with a comment to turn it on with the first path.
- CI job `openapi` in `ci.yml`, same trigger as `pint` and `tests`. It runs `npx --yes @stoplight/spectral-cli@<pinned> lint ATLANTECH/openapi/port-api.yaml --fail-severity=warn`, with no `package.json`.

### Publish

`app/Modules/Shared/Console/PublishOpenApi.php` provides `atlantech:contracts-openapi {--output=}`:
- It copies the file byte for byte. The default target is `base_path('../../contracts/openapi/port-api.yaml')`, the same pattern as `atlantech:contracts-schema`.
- It creates the `openapi/` folder if `contracts/` exists, and refuses with a clear message when `contracts/` is missing.

### Data

- Tables, migrations and enums: none.

### Behaviour

- No write chain, transactions, audit or events.
