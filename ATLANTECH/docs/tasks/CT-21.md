## 3. Design

### Endpoints

None.

### Data

- No table or migration changes.
- New enum `PlanComponentDerivedStatus`, tagged `@derived`, because the value has no column.
- Each enum already names its columns in its PHPDoc as `table.column`; the command reads those and fails on an enum that names none.

### Behaviour

`atlantech:contracts-status-vocabulary` (`composer contracts:status-vocabulary`) writes `{version, columns, derived}` with sorted keys and no timestamp, so the same enums give the same bytes.
