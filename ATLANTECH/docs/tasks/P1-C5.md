## 1. What is asked

The tablet learns, without signing in, which port it is connected to and the minimum app version it needs (`backend/atlantech_backend_tasks.md:57`, roadmap P1-C5: "Done when the app can show the port name on first launch").

**Done when:**

- [ ] `GET /api/v1/system/info` answers 200 without a session or token, with exactly `{port_id, port_code, port_name, license_mode, token_warning_days_left, min_app_version}` (CT-04 v1.1).
- [ ] `port_id` is `port_profiles.public_id`; `port_code` may be null.
- [ ] `license_mode` is always `FULL` and `token_warning_days_left` always `null` until the licence work (DEC-54).
- [ ] It is never refused with 426: an old or malformed `X-App-Version` still gets 200.
- [ ] With no `port_profiles` row or no `min_app_version` setting: 503 `SERVICE_UNAVAILABLE` (Q-C5-1).
- [ ] One reader of `min_app_version` exists, behind a Shared interface, for the 426 check of P1-C3.
- [ ] OpenAPI has the path (`info.version` 1.3.0); `RouteAbilityCoverageTest` allow-lists the public route; Pint and the full suite pass.

**Out of scope:** the 426 check itself (P1-C3) · real licence values (DEC-54) · editing `min_app_version` (PORT_GM settings screen, later task).

## 3. Design

### Endpoints

| Method and path | Role(s) and scope | Request | Success | Errors (code) |
| --- | --- | --- | --- | --- |
| `GET /api/v1/system/info` (`system.info`) | Public | — | 200 body below | 503 `SERVICE_UNAVAILABLE` |

```json
{ "port_id": "0d9f6a52-…", "port_code": "EGDAM", "port_name": "Damietta Port", "license_mode": "FULL", "token_warning_days_left": null, "min_app_version": "1.0.0" }
```

### Data

- Reads `port_profiles` (id 1) and `port_settings` (`min_app_version`), both Backend-owned. No write, no migration.

### Behaviour

- `App\Modules\Shared\Contracts\MinAppVersionSource` (interface, `minAppVersion(): string`), bound in `MasterDataServiceProvider` to `App\Modules\MasterData\Services\PortSettingMinAppVersion`. Access may use only Shared, and the 426 hook `EnsureMinAppVersion` is in Access (P2-D2), so the interface is the only placement that works. It throws 503 when the row is missing.
- Controller `App\Modules\MasterData\Http\Controllers\SystemInfoController` (invokable), outside `port.api`: no write chain, no throttle, no audit.
